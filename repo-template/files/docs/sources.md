# {{name}} — источники

> Внешние факты, на которые опираются документы `docs/` репозитория: условия поставщика, цена, закон, стандарт, документация библиотеки. Здесь лежат их записи — адрес, версия или дата страницы, дата прочтения и цитата на языке источника, — а [architecture.md](architecture.md) и журнал решений держат утверждение и ссылку на запись по её номеру, как на раздел: `sources 1.1` (RULES.md, The bar; R143 spec).
>
> Запись — подраздел «N.M» темы: один источник или одно чтение нескольких источников ради одного решения. Номер записи не меняется: новая встаёт в конец своей темы, новая тема — в конец файла. Перечитанный источник — пункт со своей датой в той же записи, а прежний текст не правится. Образец — sources spec. Итоги замеров — не здесь, а в `docs/measurements.md`, который заводит первый замер.
