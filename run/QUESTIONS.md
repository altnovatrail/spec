# QUESTIONS.md — вопросы автору без ответа `spec`

> Таблица 3 плана работ [RUN.md](../RUN.md) — вопросы автору из «Открыто» задач — в своём файле папки `run/`, на русском, как RUN.md (R153).
>
> - **Файл не читается целиком.** Задача берёт из него строки, которые называют она сама и её разделы, — `grep -n '^| В35 ' run/QUESTIONS.md`.
> - Вопрос встаёт сюда из «Открыто» задачи (правило 9 RUN.md). Ответ автора записывается туда, куда он относится, — в задачу, документ или [DEBT.md](DEBT.md), — и строка уходит. С архивом эпика запись начала таблицы уходит в него («Как устроен план: эпики» RUN.md).
