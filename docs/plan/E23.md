## Таблица 1. Текущий эпик — E23. ИИ сам проверяет задачу с листочка

**Результат** — задачу с листочка любой формы проверяет модель: один вызов «Проверить» даёт по каждому месту ответа вердикт, место ошибки, слова тьютора и лестницу подсказок; «Эту задачу не проверить» остаётся только там, где ответа нет или он нечитаем.
- Решения и документы `spec` — T284; контракты, `tutor`, `api`, `app` и выкладка в prod — T285, задача across repositories (R166).
- Цели E21 входят сюда: «Проверить» можно нажать до ответа — модель говорит «пока верно» или показывает первую ошибку; длинное верное решение получает вердикт той же модели.

**Основа** — на 2026-11-23, `spec` `main` 022d5cb.
- Кейс `draft/case-20261123T043256-1638b809.json` (выгрузка debug, работа автора): сетка 3×3 сумм — «Эту задачу не проверить»; Claude.ai по тому же скриншоту проверил. Причина — конвейер R162, не модель:
  - чтение условия разрезало сетку на шесть отдельных `□ + □ + □ = N`, связь строк и столбцов через общие клетки потерялась;
  - решатель отвечает только `number`, `choice` или `none` («several answers» → `none`) — Haiku, Sonnet и Opus вернули `none` по всем шести;
  - каскад поднялся до Sonnet и Opus на верном `none`: $0.0195 из $0.0217 проверки;
  - чтение работы сопоставило ответы только строкам, столбцы остались без `read`.
- В вырезке нет задания над сеткой: если там «числа от 1 до 9 по одному разу», ответ ученика неверен, а Claude.ai сказал «верно».

**Решено автором (2026-11-23)**:
- **Вердикт по задаче с листочка выносит модель**, не программа по ключу: страница может нести задачу любой формы, программа не знает всех классов, модели улучшаются; ошибка модели иногда лучше, чем «не знаю» в каждой пятой задаче. Отвергнуто: расширить виды ключа (условия, множество ответов) при вердикте программы. Задачи модулей — без изменений: вердикт программы по ключу.
- **Что получает модель** — Image 1, чистая вырезка условия; Image 2, работа — вырезка со штрихами ученика и штрихи листа, цветная по R172; Image 3, задание над рамкой — `FindTasks` даёт его рамку, без текста (R134 `tutor` держится), `app` вырезает его из фото; размеры картинок; язык интерфейса; возрастная категория; история попытки — прошлые вердикты, показанные ступени, прежние слова тьютора, её собирает `api`.
- **Что модель возвращает** по каждому месту ответа: `verdict` — `correct`, `incorrect`, `unreadable`, `no_answer`; `confidence`; `read`; `assumptions` — что додумала в условии; `errors[]` — рамка на Image 2, место словами, вид, пояснение; скрытые `solution` и `answer`; `tutor_text`; `hints[]` — 2–3 ступени. Подсказки и место ошибки — без второго вызова.
- **Штрихи и история письма в проверку не идут**: история — биометрия по законам ряда штатов (privacy 3.4), картинка уже идёт. Польза порядка блоков — Д300.
- **Подсказка до первой проверки** — тот же вызов с тем, что написано: `no_answer` и лестница.
- **Каскад** Haiku 5.5 · `high` → Sonnet 5.5 · `medium` → Opus 5.5 · `medium` — дальше при `confidence: low`, `unreadable` или ответе не по схеме; неуверенное «неверно» последней модели показывается, тьютор говорит мягче.
- **Порога точности до выпуска нет**: допуск словом автора до 2027-01-17, как у вызовов задач с листочка сейчас; сначала замер на eval set вердиктов, отдельно — доля ложных «неверно».
