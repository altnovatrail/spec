- **Сделать:** список ошибок — от автора по ходу, по одной или группами: что видно, где, как повторить. Ход: `xrepo up e20 …` с репозиториями, которые задевают ошибки, новый — тем же `up`, когда понадобится; ошибку сначала повторить на стенде `xrepo serve`; правка вида — сначала состояние макета `draft/mockup` в клоне `spec` и одобрение автора (R148), исправление без изменения вида — сразу в код; малое — главная сессия, большой кусок — субагент (`R166`); к исправлению — тест, который без него падает; `xrepo test` тронутого; проверка автора на стенде. Ошибка, которая требует решения, — вопрос автору до кода; что отложено — строка `run/DEBT.md`.
- **Коммиты:** одна ветка `e20`, один коммит этой задачи в каждом тронутом репозитории, учёт в клоне `spec` в том же коммите, push после коммита; PR нет — это T255.
- **Как проверить:** каждая ошибка не повторяется на стенде — автор; `xrepo test` тронутого зелёный, с тестами браузеров (`--browser`) там, где правка в них видна; правка вида — против одобренного макета.
- **Мой шаг:** назвать ошибки; одобрить макет правок вида; проверить на стенде.
- **Стоимость:** вызовы моделей на стенде — только если ошибка в словах тьютора, под лимитом $2 сессии стенда.
- **Разделы:** `R166`, R148, R159; [draft/mockup/README.md](../../draft/mockup/README.md); [tools/orchestrator/README.md](../../tools/orchestrator/README.md), «A task across repositories».
